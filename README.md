# 2024/25 Apprenticeship Data Dashboard (England)

## Overview
This project presents an interactive Power BI dashboard summarising apprenticeship activity in England for the 2024/25 academic year. The dashboard focuses on key lifecycle metrics, including new apprenticeship starts, active participation, and completions, with clear breakdowns by region, sex, and apprenticeship level.

The aim of this dashboard is to demonstrate clear, insight-led data visualisation, appropriate metric selection, and thoughtful dashboard design rather than maximising the number of visuals displayed.

---

## Key Questions Answered
- How many learners started apprenticeships in England in 2024/25?
- How does participation compare to new starts and completions?
- Which regions have the highest number of new apprenticeship starts?
- How are new starts distributed by sex?
- Which apprenticeship levels attract the most new starters?

---

## Dashboard Features
- **Headline KPIs** showing:
  - Learners starting apprenticeships
  - Learners participating in apprenticeships
  - Apprenticeship completions
  - Year-on-year change in starts
- **Regional breakdown** of apprenticeship starts using a horizontal bar chart
- **Gender split** of apprenticeship starts using a donut chart
- **Apprenticeship level breakdown** focusing specifically on *starts* (Advanced, Higher, Intermediate)
- Clear visual hierarchy and consistent formatting across the page
- Contextual description and data source attribution included directly on the dashboard

---

## Design Considerations
- Distinct treatment of *starts*, *participants*, and *completions* to avoid misleading comparisons
- Use of additive measures only where appropriate (e.g. starts by region and level)
- Avoidance of non-additive breakdowns (e.g. participants by level) where they could distort interpretation
- Emphasis on clarity, consistency, and stakeholder readability

---

## Tools & Skills Demonstrated

- Handling of non-additive measures
